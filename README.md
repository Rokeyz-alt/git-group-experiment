# 老年人综合评估系统（老年就医预问诊 + 老年综合评估）

## 项目定位
面向老年人就医预问诊场景，通过 AI 语音交互引导老年人完成 21 张量表的语音化采集，自动生成结构化老年综合评估报告，供医生诊疗参考。

## 目录结构
- docs/：需求与计划文档
- backend/：FastAPI 后端代码
  - app/utils/：患者身份信息脱敏工具
  - tests/unit-test/：单元测试用例
