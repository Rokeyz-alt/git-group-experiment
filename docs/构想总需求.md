# 老年人综合评估系统 —— 构想总需求

## 项目概述
通过 AI 语音多轮引导完成 21 张量表采集，减少医护人工问诊与计分时间；识别不清不臆测，保留原录音交医生复核；评分由确定性规则引擎完成；方言交互、大字号、语音引导、断点续答；录音加密存储、知情同意、权限控制、日志审计。

## 核心痛点
方言沟通障碍、表达理解受限、量表体量大耗时长、采集易漏易错、家属代答干扰、语音识别臆测风险、中断不可恢复、隐私合规风险、医生端负担重、结果呈现不标准。

## 功能模块
1. 用户与权限管理
2. 预问诊语音采集（多轮引导、方言识别、跑题拉回、未听清处理、代答识别、断点续答）
3. 基础信息采集（证件 OCR，敏感号段不外显）
4. 量表评估（14 张访谈问答类 + 7 张体格操作类）
5. 报告生成（汇总得分、风险分级、导出打印共享）
6. AI 能力支撑（方言 ASR/TTS、OCR、语义理解；评分由规则引擎完成）
7. 数据安全与合规（加密存储、知情同意、按需销毁、访问权限、日志审计）
